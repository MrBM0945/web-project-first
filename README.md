# Студентське портфоліо

**Робоче посилання на сайт (GitHub Pages):** [https://mrbm0945.github.io/web-project-first]

Персональне портфоліо студента спеціальності "Прикладна математика". Проєкт містить інформацію про мою освіту, улюблені дисципліни, навички, проєкти, а також розділи з хобі (книги, музика, аніме). Сайт розроблено з дотриманням принципів семантичної верстки та доступності (a11y).

---

## 1. Адаптивність (Breakpoints)
Сайт розроблено за підходом **Mobile First**. Увесь базовий CSS написаний для мобільних пристроїв, а далі через медіа-запити додається складніша сітка.

- **Mobile (до 768px):** Базовий макет. Весь контент йде в одну колонку (`flex-direction: column` або `grid` з 1 колонкою). У навігації працює "бургер-меню" на чистому CSS (через чекбокс).
- **Tablet (`min-width: 768px`):** Бургер-меню зникає, навігація вибудовується в один горизонтальний рядок. Секція "Про мене" розділяється на фото та опис, картки (аніме, проєкти) стають у 2 колонки. Галерея також розбивається на 2 колонки.
- **Desktop (`min-width: 1200px`):** Максимальна ширина контейнера 1200px. Секція "Про мене" стає складною Grid-сіткою на 3 колонки (сайдбар переїжджає наверх в окрему колонку). Галерея фотографій перетворюється на асиметричну мозаїку на 3 колонки. Ширина текстових блоків обмежується до `70ch` для комфортного читання.

## 3. Перевірка контрастності (WebAIM Contrast Checker)
Для забезпечення доступності сайту підтримується світла та темна теми (`prefers-color-scheme`). Перевірено 3 найризикованіші пари кольорів:

1. **Кнопки (Акцентний блок):** 
   - *Проблема:* Спочатку текст на синіх кнопках був білим (`#ffffff`), що давало низький контраст (2.57:1).
   - *Вирішення:* Колір тексту на `.btn--primary`, `.btn--submit` та `.skip-link` змінено на темний `#151515`. 
   - *Результат:* Контрастність складає **7.08:1 (Pass AAA)**.
2. **Основний текст (Світла тема):**
   - Фон сторінки (`hsl(210, 20%, 98%)`) та колір тексту (`hsl(210, 20%, 20%)`).
   - *Результат:* Контрастність — **12.5:1 (Pass AAA)**.
3. **Основний текст (Темна тема):**
   - Темний фон сторінки (`hsl(210, 20%, 10%)`) та світлий текст (`hsl(210, 20%, 95%)`).
   - *Результат:* Ідеальна контрастність для нічного режиму — **14.8:1 (Pass AAA)**.
